# Physics Equation Solver

A simple static website that lets you solve physics equations by entering an equation, known values, and the variable to solve for.

## Features

- Accepts equations like `F = m * a` or `v^2 = u^2 + 2 a s`
- Accepts known values in a comma-separated list like `m=2, a=9.81`
- Uses client-side symbolic solving with Nerdamer
- Displays results and instructions in the browser

## Run locally

1. Open `index.html` in a browser
2. Enter your equation, values, and the variable you want to solve for
3. Click **Solve equation**

## Example

- Equation: `F = m * a`
- Known values: `m=5, a=9.81`
- Solve for: `F`

Result: `F = 49.05`
